# Changelog

User-visible changes are recorded here. This project follows a simple release version scheme; each published release is tagged in Git.

## 0.1.4 — Initial public release

This is the first public Verbum release.

- Read three bundled offline Bible editions: World English Bible Catholic Edition, Douay-Rheims, and the Clementine Vulgate.
- Search Scripture and save bookmarks, highlights, personal notes, and reading history locally.
- Browse daily Scripture and the liturgical calendar, and listen with Android text-to-speech.
- Add daily verse, daily lectionary, and compact short-verse widgets.
- Select System, Light, or Dark appearance; Android 12 and later can use Material You dynamic colors.
- Browse additional language editions with source, license, and canon coverage shown in the catalog.
- Use interface resources in English, Malayalam, Tamil, Hindi, Telugu, Kannada, and Marathi.

### Known limitations

- The bundled daily Mass reading citations are incomplete; the liturgical calendar does not imply full lectionary coverage.
- Several regional Bible downloads have 66 books and are explicitly labeled incomplete for the Catholic canon.
- Some listed editions remain unavailable until their source format or redistribution terms are ready.
- Dynamic wallpaper colors require Android 12 or later and system support.

Release assets and signing status will be listed on the GitHub release page when published.
